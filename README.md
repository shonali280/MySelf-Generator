# MySelf Profile Generator

A simple and responsive personal profile generator built using HTML, CSS, and JavaScript.

Users can enter their personal information and instantly generate a profile card.

## Features

- Enter name, age, gender, and city
- Add favourite sport and ambition
- Generate a personal profile instantly
- Clean and responsive user interface
- Simple DOM manipulation using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live Demo

[View MySelf Profile Generator](https://shonali280.github.io/MySelf-Generator/)

This project was created to practice front-end web development and JavaScript DOM manipulation.
